[[sut]]
= System under test

This chapter describes Roc at commit `{roc-commit}` as it bears on security: what the shipped `roc` binary is made of, which inputs it accepts, who supplies them, where trust is extended, and which contracts Roc specifies for package and platform authors. Every finding is assessed against this description. Each statement carries an evidence label (<<evidence-labels>>). Code citations are pinned to `{roc-commit}`. "Tested" statements were run on macOS 26.3 (Darwin 25.3.0, aarch64) on 2026-09-30, reading already-fetched archives only. Nothing was built.

== Identity

* The compiler is written in Zig. The minimum toolchain is Zig 0.16.0 (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/build.zig.zon#L4[`build.zig.zon:4`] `.minimum_zig_version = "0.16.0",`). The local toolchain used for inspection reports `0.16.0` (Tested: `zig version` printed `0.16.0`).
* The version string is `<build mode>-<git short sha>`, for example `release-fast-abc12345` (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/build.zig#L3303[`build.zig:3303`] `pub const compiler_version = @import("std").fmt.comptimePrint("{s}-{s}", .{`). It can be overridden at build time. Nightly builds pass their release tag (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/build.zig#L3206[`build.zig:3206`] `const compiler_version_override = b.option([]const u8, "compiler-version",`). `roc version` prints it (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/cli/cli_args.zig#L548[`src/cli/cli_args.zig:548`] `version          Print the Roc compiler's version`).
* The repository has no `SECURITY.md` or other security policy at `{roc-commit}` (Tested: `git ls-tree -r --name-only {roc-commit} | grep -i security` printed only `design/editor/plugins/security.md`, an editor design note).

== Dependencies and shipped components

Every external dependency is fetched by URL and pinned by its Zig package hash in `build.zig.zon`. Zig verifies that hash when it fetches the package (Examined-source: Zig build system documentation, "Package management", https://ziglang.org/learn/build-system/, accessed 2026-09-30).

=== Prebuilt `roc_deps_*` archives

* One `roc_deps_<target>` archive per host target. Each is fetched from the `roc-lang/roc-bootstrap` release `llvm-21.1.8-scaling-2` (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/build.zig.zon#L52[`build.zig.zon:52`] `.url = "https://github.com/roc-lang/roc-bootstrap/releases/download/llvm-21.1.8-scaling-2/aarch64-macos-none.tar.xz",`).
* The aarch64-macos archive is fetched locally at `zig-pkg/N-V-__8AAI7KVRG6J1Tp9i70olobTIwsFtoF_O54b2H3PnHZ`, which matches the pinned hash (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/build.zig.zon#L53[`build.zig.zon:53`] `.hash = "N-V-__8AAI7KVRG6J1Tp9i70olobTIwsFtoF_O54b2H3PnHZ",`). * Versions read from that archive (Tested: `grep` on the headers named):
** LLVM 21.1.8: `include/llvm/Config/llvm-config.h` line 79 is `#define LLVM_VERSION_STRING "21.1.8"`. The same header enables `LLVM_ENABLE_ZLIB 1` and `LLVM_ENABLE_ZSTD 1`.

=== URL packages and platforms

* The compiler's resolver fetches bundles through `CtxFetcher` into a private staging directory, then renames it into the cache (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L2217[`src/compile/package_resolution.zig:2217`] `const expanded_bytes = self.fs.fetchUrl(self.gpa, url, staging_dir, max_expanded_bytes)`; https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L2234[`src/compile/package_resolution.zig:2234`] `self.fs.rename(staging_dir, package_dir) catch {`).
* Every `BuildEnv` on a native host gets real HTTP download support (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/compile_build.zig#L362[`src/compile/compile_build.zig:362`] `env.filesystem.vtable.fetchUrl = fetch_fn;`). == Trust boundaries

* *Source code executes at compile time, in the compiler process*:
** Every checked top-level expression that can be evaluated without effectful calls is evaluated (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/design.md#L841[`design.md:841`] `every selected compile-time root that can be evaluated without effectful calls`).
** On native hosts this is dev-backend machine code running inside `roc` (see above).
** The code comes from the application, every package it imports (including transitive URL packages), and the platform.
** A package author and a platform author are equally exposed to their own URL dependencies when they run `roc check`, `roc docs`, `roc bump` or `roc build`.
* *No I/O at compile time*: the compile-time host supplies an empty hosted-function table, so effectful platform functions are not callable (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/eval/compile_time_host.zig#L136[`src/eval/compile_time_host.zig:136`] `.hosted_fns = builtins.host_abi.emptyHostedFunctions(),`). Compile-time code can still allocate, loop and recurse. Any memory-safety defect in generated code (see "Security-relevant miscompilation") executes with the compiler's privileges (Inferred).
* *No resource limits in release builds, by design*: "Release builds of the compiler must never impose artificial resource limits on compile-time evaluation" (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/design.md#L1360[`design.md:1360`] `Release builds of the compiler must never impose artificial resource limits on`). The interpreter's call-depth guard applies only in Debug builds (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/eval/interpreter.zig#L2336[`src/eval/interpreter.zig:2336`] `if (comptime builtin.mode == .Debug) {`). A stack overflow is converted into a compile-time crash report (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/eval/compile_time_host.zig#L217[`src/eval/compile_time_host.zig:217`] `/// Record a caught stack overflow exactly the way a Roc`). No sandbox, CPU budget or memory cap was found (Inferred: from the design rule and the absence of such code in `src/eval/compile_time_*.zig`). Compiling untrusted Roc code is therefore a denial-of-service exposure, and its memory safety depends on the correctness of the compiler.
* *URL package integrity*:
** Integrity rests on the base58 BLAKE3 hash that is the last path segment of the URL (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/unbundle/download.zig#L109[`src/unbundle/download.zig:109`] `/// - Have the base58-encoded blake3 hash as the last path segment`).
** Nothing is signed. The hash protects against tampering in transit or on the server. It does not protect against a malicious author who publishes a URL with a matching hash (Inferred).
** Transport must be https, except plain http to loopback hosts (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/base/url.zig#L291[`src/base/url.zig:291`] `return std.mem.startsWith(u8, url, "https://") or`). A `localhost` URL must resolve to loopback (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/unbundle/download.zig#L207[`src/unbundle/download.zig:207`] `try localhost.requireLoopback();`). Whether `std.http.Client` follows a redirect from https to http is Unverified.
* *The hash is verified after extraction*:
** Files are written as the compressed stream is hashed. The hash is compared only after the tar walk ends (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/unbundle/unbundle.zig#L766[`src/unbundle/unbundle.zig:766`] `// Verify hash after all data is read`; https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/unbundle/unbundle.zig#L624[`src/unbundle/unbundle.zig:624`] `if (!std.mem.eql(u8, &actual_hash, &self.expected_hash)) {`).
** Unverified content is therefore parsed by zstd and tar and written to disk before the check. It lands in a staging directory that is deleted on failure (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/cli/main.zig#L7512[`src/cli/main.zig:7512`] `std.Io.Dir.cwd().deleteTree(ctx.io.std_io, staging_dir_path) catch {};`).
** Tar paths are rejected if they are absolute or contain `..` or `.` (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/unbundle/unbundle.zig#L327[`src/unbundle/unbundle.zig:327`] `if (std.mem.eql(u8, component, "..")) {`). Symlink entries are validated and then skipped, not created (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/unbundle/unbundle.zig#L760[`src/unbundle/unbundle.zig:760`] `// TODO: Add symlink support to ExtractWriter interface`).
* *Decompression limits*:
** Package bundles have a 10 MiB default expanded-size limit (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L81[`src/compile/package_resolution.zig:81`] `pub const default_max_package_expanded_bytes: u64 = 10 * 1024 * 1024;`). Platforms are exempt (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L42[`src/compile/package_resolution.zig:42`] `//! size is limited (platforms are exempt, since an app declares exactly one`).
** The CLI `resolveUrlBundle` path passes no limit (see above). The download itself has no size cap.
* *Local cache*:
** The cache is shared by every roc process on the machine. A hash-named directory is trusted as complete (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L36[`src/compile/package_resolution.zig:36`] `//! hash-named directory with a rename. A directory named after a hash means`).
** Cached bundles are not re-hashed when they are read (Inferred: from the warm-cache design at https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L30[`src/compile/package_resolution.zig:30`] `//! invalidation, and warm-cache resolution touches no network and parses no`).
** Checked-module cache entries have no body checksum (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/coordinator.zig#L230[`src/compile/coordinator.zig:230`] `// There is no body checksum: cache entries are written to a temp file and atomically`).
** Anyone who can write to the cache directory can therefore substitute package source or serialized compiler state (Inferred). The permissions on the cache directory are Unverified.
* *Platform hosts are fully trusted*: host objects are native code linked into the output. Their symbol tables are parsed by Roc code and their contents by LLD in-process (see Inputs). A platform author is trusted by design. A platform author who links third-party host libraries extends that trust to those libraries' producers (Inferred).
* *The compiler process runs with the privileges of the invoking user*. No privilege dropping or OS sandbox was found (Inferred: no such code in `src/cli/main.zig` or `src/compile`).

== Ecosystem contracts

These are the rules Roc specifies for package and platform authors. A weakness in a contract affects every third-party package or platform that follows it, so each contract is a row in the attack-surface map.

* *Package identity and versioning*:
** A URL package is identified by its URL id plus its major version. Within a group, the highest mentioned minor.patch wins (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L3[`src/compile/package_resolution.zig:3`] `//! Packages downloaded from URLs are identified by their url id (the URL path`).
** The same version served with two different hashes is an error (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_resolution.zig#L912[`src/compile/package_resolution.zig:912`] `"The same package version is being served with two different content hashes:\n\n" ++`).
** A local path that cannot be resolved falls back to its lexically normalized form for identity (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_identity.zig#L6[`src/compile/package_identity.zig:6`] `//! resolved on disk (missing file, editor-overlay-only file) falls back to its`).
** URL identity is the full URL plus the span of its URL id (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/compile/package_source.zig#L1[`src/compile/package_source.zig:1`] `//! Source URL identity for packages downloaded from URLs: the full URL plus`).
* *Bundle format*: a `.tar.zst` produced by `roc bundle`, named by the BLAKE3 hash of the compressed bytes. It can include platform host object files (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/bundle/bundle.zig#L1[`src/bundle/bundle.zig:1`] `//! Bundle and unbundle a roc package and everything it requires, including host object files if the`).
* *Platform selection*: exactly one platform per resolved graph. URL declarations must agree on URL, version and hash. Hosted lowering is authorized only by the selected platform's hosted declarations (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/design.md#L1556[`design.md:1556`] `platform requirements. Hosted lowering remains authorized solely by the`).
* *Host ABI*:
** Hosts must define a fixed runtime symbol set: `roc_alloc`, `roc_dealloc`, `roc_realloc`, `roc_dbg`, `roc_expect_failed` and `roc_crashed` (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/builtins/shim_symbols.zig#L68[`src/builtins/shim_symbols.zig:68`] `pub const runtime_set = [_][:0]const u8{`). They must also define the hosted functions the app calls.
** Allocation semantics are specified on `RocOps` (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/builtins/host_abi.zig#L158[`src/builtins/host_abi.zig:158`] `roc_alloc: *const fn (*RocOps, usize, usize) callconv(.c) ?*anyopaque,`).
** Roc verifies before linking that the host inputs define the needed symbols (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/cli/host_symbols.zig#L1[`src/cli/host_symbols.zig:1`] `//! Pre-link verification that the platform's host inputs define the symbols`).
* *Platform-supplied artifacts*: the platform header's `targets:` section names per-target files to link. `roc build` and `roc bundle` validate that they exist (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/src/cli/platform_validation.zig#L6[`src/cli/platform_validation.zig:6`] `//! - Validating target files exist on disk`). Whether those paths are confined to the platform directory is Unverified.

== Compiler phases

Source is parsed (`src/parse`), canonicalized (`src/canonicalize`) and type-checked (`src/check`, `src/types`). Compile-time roots are then evaluated (`src/eval`). The checked modules are lowered through the post-check IRs in `src/postcheck` (Monotype, Monotype Lifted, Lambda Solved and related stages) to LIR with explicit ARC (`src/lir`). Finally a backend (`src/backend/dev`, `src/backend/llvm`, `src/backend/wasm`), the interpreter, or LirImage consumes the LIR, and the output is linked by embedded LLD (`src/cli/linker.zig`) (Examined-code: https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/design.md#L32[`design.md:32`] `checked modules`; https://github.com/roc-lang/roc/blob/da73825fb7a159ecd24a70b93a1e1a2bb4648140/design.md#L41[`design.md:41`] `-> backend, interpreter, or LirImage`). Package fetch and extraction (`src/compile`, `src/unbundle`) run before parsing of dependencies.
